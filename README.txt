The program will start when a valid program selection is entered and stop when "####" is entered

The door lock code is "1972"
The door will lock when an incorrect code is entered

There are five demo programs to choose from:
"#A11" will run "Stop on Detection"
"#B22" will run "Turn Left"
"#C33" will run "Turn Right"
"#D44" will run "Turn 180"
"BBBB" will run "Move backward five seconds"
